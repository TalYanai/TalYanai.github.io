FLAGSHIP Docker · Azure · Power BI

Garmin Fitness Analytics Pipeline

End-to-end automated fitness analytics: export a CSV from Garmin Connect, send it to Telegram — the pipeline handles everything else. Claude AI parses and normalizes activities, PostgreSQL stores them, Power BI visualizes them. Zero manual steps after the export.

View Repo

Data Pipeline Flow

📱 Garmin Connect CSV 💬 Telegram Bot ⚙️ n8n Webhook (8 nodes) 🤖 FastAPI + Claude Tool Use 🐘 PostgreSQL 15 📊 Power BI (4-page dashboard)
  • ▸ Docker — 4-service Docker Compose stack (nginx · n8n · FastAPI · PostgreSQL) deployed with a single bash scripts/deploy.sh on a fresh Azure Ubuntu VM
  • ▸ Cloud Deploy — Azure VM (Standard_B2s) + nginx reverse proxy + Let's Encrypt SSL with monthly auto-renewal via cron
  • ▸ AI Pipeline — Claude Tool Use API guarantees schema-valid JSON for every parsed activity; handles unit conversions (miles→km, ft→m, HH:MM:SS→minutes) automatically
  • ▸ Automation ROI — re-send the same CSV any number of times; smart dedup (ON CONFLICT DO NOTHING) means zero duplicate rows, zero cleanup work
  • ▸ Secure BI — Power BI connects to PostgreSQL over Tailscale VPN; no database port exposed to the internet
Python FastAPI Claude API · Tool Use n8n PostgreSQL 15 Power BI · DAX Docker Compose Azure VM nginx · Let's Encrypt Tailscale VPN

Multi-Agent Personal Assistant

A production AI assistant running 24/7 on Railway.app. An orchestrator agent (Claude) coordinates five specialized sub-agents every morning, synthesizing a personalized daily brief delivered to Gmail at 08:00 — plus a live Telegram Q&A bot that answers Hebrew and English questions on demand.

  • ▸ Cloud Deploy — runs as a Railway.app worker process (Procfile-based); zero infrastructure maintenance, auto-restarts on crash

  • ▸ Automation Pipeline — APScheduler fires the full multi-agent pipeline at 08:00 daily with no human trigger; synthesized brief emailed automatically via Gmail SMTP
  • ▸ Real-time Data — live stock prices (yfinance), Israeli NBA player stats (nba_api), Google Calendar events, personalized workout JSON
  • ▸ Bilingual NLU — understands questions in Hebrew and English; responds in the same language as the query

Vanilla JS · Chart.js · No backend

Personal Finance Tracker

A full-featured investment portfolio manager and tracker built as a single HTML file — no server, no build step, no login. Tracks holdings, visualizes performance with interactive Chart.js charts, fires browser alerts on threshold crossings, and exports to CSV / Excel / PDF / JSON.

View Repo
  • ▸ Data Pipeline — LocalStorage as the persistence layer; all portfolio data flows through a single-page reactive UI with Chart.js-rendered equity curves and breakdown charts
  • ▸ Alert Automation — browser Notification API fires when a holding crosses a user-defined gain/loss threshold — no backend polling required
  • ▸ Calendar Integration — generates iCal events for dividend dates and rebalancing reminders; one-click import to Google Calendar or Outlook
  • ▸ Multi-format Export — one-click CSV / Excel / PDF / JSON dump for any date range; full backup/restore via JSON
  • ▸ Zero Infra — runs offline, requires no server, no npm install, no API keys; open in any browser

Leaflet.js · 40+ Locations · Python Scraper

Our Map — Interactive Memory Atlas

A full-screen interactive map with polaroid-style photo pins for personal travel memories. Each location is a Leaflet.js marker that expands into an animated polaroid photo card on hover. Data-driven from a single JSON file; adding a new pin requires one JSON entry.

View Repo
  • ▸ Geospatial Visualization — Leaflet.js on OpenStreetMap tiles; custom HTML markers positioned at precise GPS coordinates
  • ▸ Animated Polaroids — CSS transform hover effects (scale + rotate) with drop shadows; smooth transitions via GPU compositing
  • ▸ Data-driven — 40+ locations loaded from data.json; the entire map rebuilds from JSON with no code changes
  • ▸ Automated Image Fetch — download_images.py batch-downloads all location photos from source URLs, renames them to match JSON keys
  • ▸ Zero Build — single index.html, CDN assets, runs fully offline; no npm, no bundler, no server needed
